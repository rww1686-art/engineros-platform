# Engineros Platform

Engineering Intelligence Platform (EIP) — базова платформа для формування інженерної бази компаній України, подальшої побудови графа зв’язків, рейтингу EOI та інтеграції тендерних даних.

## Статус

**Етап 1 завершено.** Базова архітектура, API, модель компанії, міграції, PostgreSQL-інтеграція та автоматизований контроль якості реалізовані й перевірені в GitHub Actions.

## Реалізовано в Етапі 1

- FastAPI-застосунок і endpoint перевірки стану `/health`;
- асинхронне підключення до PostgreSQL через SQLAlchemy;
- Alembic-міграції;
- доменна модель `Company`;
- Pydantic-схеми запитів і відповідей;
- repository та service layers;
- CRUD API для компаній;
- пошук, фільтрація, сортування та пагінація;
- базова валідація даних і ЄДРПОУ;
- unit та PostgreSQL integration tests;
- GitHub Actions CI з перевірками Alembic, Ruff, MyPy і Pytest;
- Docker-конфігурація для локального середовища.

## Перевірка якості

CI виконує:

```bash
alembic upgrade head
ruff check .
mypy app
pytest
```

Остання перевірка Етапу 1 успішно пройшла на Python 3.12 із PostgreSQL 16.

## Локальний запуск

```bash
cp .env.example .env
docker compose up --build
```

Перевірка API:

```bash
curl http://localhost:8000/health
```
