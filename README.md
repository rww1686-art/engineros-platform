# Engineros Platform

Engineering Intelligence Platform (EIP) — репозиторій для реалізації Етапу 1.

## Поточний статус

Репозиторій ініціалізовано. Програмна розробка ще не розпочата.

## Мета Етапу 1

Підготувати основу для:

- структури даних;
- бази компаній України;
- моделі зв’язків;
- рейтингової системи EOI;
- інтеграції тендерних даних.

## Географічний пріоритет

1. Західна Україна.
2. Центральна Україна.
3. Північна Україна.
4. Південна Україна.
5. Східна Україна.

## Стан реалізації

- Архітектурне планування: виконано.
- Репозиторій: створено та ініціалізовано.
- Код застосунку: не створено.
- Схема бази даних: не створена.
- API: не створено.
- Інфраструктура: не налаштована.

Розробка має розпочинатися окремим підтвердженим завданням.
